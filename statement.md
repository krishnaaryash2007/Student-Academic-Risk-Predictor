Student Academic Risk System
1. Problem Statement
Students' academic performance depends on several factors such as attendance, marks, quiz performance, assignment completion, and previous academic results. Checking all these factors manually can make it difficult to identify students who may need additional academic support.The Student Academic Risk System is developed to provide a simple way to organize student academic information, calculate an overall performance score, identify the student's academic risk level, and provide a basic recommendation.
The project uses rule-based analysis implemented with Python programming concepts rather than machine learning.

2. Scope of the Project
The scope of the project includes:
- Managing basic student academic records.
- Adding, displaying, searching, and deleting student information.
- Analyzing attendance and marks.
- Calculating an overall academic performance score.
- Classifying students into Low Risk, Medium Risk, or High Risk.
- Providing basic recommendations according to the identified risk level.
- Displaying the performance of students in a class summary.
The current project stores student information temporarily in memory while the program is running.
Permanent database storage, advanced prediction models, and machine learning are outside the scope of the current version.

3. Target Users
The intended users of the system are:
- Students - To understand their academic performance and risk level.
- Teachers - To review basic academic information of students.
- Academic Mentors - To identify students who may require additional academic attention.
The project is designed as a simple academic analysis system and is suitable for basic educational use.

4. High-Level Features
The system provides the following main features:
->Student Management
- Add student details.
- Display student records.
- Search for a student using registration number.
- Delete student records.

->Attendance Analysis
The system checks the attendance percentage and displays a status such as:
- Excellent Attendance
- Very Good Attendance
- Good Attendance
- Low Attendance

->Marks Analysis
The system checks the marks percentage and displays a status such as:
- Excellent Marks
- Very Good Marks
- Good Marks
- Low Marks

->Performance Analysis
The system calculates an overall performance score using:
- Attendance
- Marks
- Quiz
- Assignment
- Previous Result

->Risk Identification
The performance score is used to classify the student as:
- Low Risk
- Medium Risk
- High Risk

->Recommendation
The system provides a basic recommendation according to the identified risk level.

->Class Summary
The system calculates and displays the performance score of each student and the overall class average.

5. Project Objective
The main objective of the project is to demonstrate how basic Python programming concepts can be used to develop a simple academic performance analysis and rule-based early warning system.
The project focuses on programming fundamentals, modular design, data handling, conditional logic, and problem-solving.
